# Digi-Chest
(README created with assistance from OpenAI's Codex)

## Digi-Chest Description
The Digi-Chest application will turn ordinary walks and exercise into a game. Similar to geocaching, Digi-Chest provides users hints to "buried treasure". The user will need to walk to a certain area on the map to play a mini game to retrieve the buried treasure.

## Project Status

Digi-Chest is currently a blank Expo and React Native starter project. The application is being built from scratch.

## Getting Started

### Prerequisites

Install:

- Node.js
- npm
- Expo Go, an Android emulator, or an iOS simulator

### Installation

Clone the repository, enter the project folder, and install dependencies:

```bash
npm install
```

### Running the Application

Start the Expo development server:

```bash
npm start
```

Additional commands:

```bash
npm run android
npm run ios
npm run web
```

## Type Checking

Check the TypeScript code without starting the application:

```bash
npm run typecheck
```
